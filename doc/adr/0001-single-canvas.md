# One Canvas for launcher items

The user approved replacing all pages with one freely pannable and zoomable Canvas on 2026-11-02. A flat item collection and signed positions replace finite page ownership, so placement and persistence no longer depend on monitor dimensions or page capacity. Item rectangles cannot overlap; former page arrangements migrate into adjacent regions to preserve relative positions instead of repacking the whole layout.

Boxes are removed. Before replacing legacy data, retain the original configuration in a timestamped backup, including Box text. Preserve launcher item IDs, Folder contents, widget state and exclusive Dock ownership. Run existing per-page widget migrations before flattening to avoid merging unrelated instances.
